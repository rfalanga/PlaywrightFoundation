# PlaywrightFoundation

I'm following the Pluralsight Playwright Foundations with C# course by Erik Dahl, although I'll be using .NET 9, rather than .NET 8 as he did in the course.

## Docker Desktop

I've found that it is necessary to have Docker Desktop installed and running in order to run the Playwright tests in this course. If you don't have it installed, you can download it from [Docker's official website](https://www.docker.com/products/docker-desktop/).
